# vibe-starter

The hour-one app for the MindLogic vibe-coding workshop: a work board backed by Supabase, deployed on Vercel.

1. Use this template (green button) or `gh repo create my-board --template mindlogic-ai/vibe-starter --private --clone`
2. `npm install`, then `claude` in the folder and say "let's start hour one".
3. Claude walks you through `.env.local`, the SQL, GitHub, and Vercel using the vibe-kit skills.

Files that matter: `app/page.tsx` (the board), `lib/supabase.ts` (the connection), `supabase/schema.sql` (the table), `CLAUDE.md` (the rules Claude follows here).
